## Manual Instalasi Program
1. Akses ke GitHub [https://github.com/Alpucap/clustering-wilayah](https://github.com/Alpucap/clustering-wilayah)
2. Kemudian, clone repository ini dengan menggunakan `git clone https://github.com/Alpucap/clustering-wilayah.git` pada terminal atau command prompt.
3. Setelah proses clone selesai, masuk ke project dengan menjalankan perintah `cd clustering-wilayah`
4. Setelah itu, buat virtual environment, dengan menjalankan perintah `python -m venv venv`
5. Aktifkan virtual environment dengan menjalankan `venv\Scripts\activate` (windows) atau `source venv/bin/activate` (macOS/Linux)
6. Kemudian, install seluruh dependensi project dengan menjalankan perintah `pip install -r requirements.txt`
7. Jalankan aplikasi dengan menjalankan perintah `streamlit run app.py`
8. Terakhir, akses aplikasi ini melalui browser dengan membuka alamat [http://localhost:8501](http://localhost:8501)
